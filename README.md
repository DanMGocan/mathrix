# Mathrix source archive

The current application is on the [main branch](https://github.com/DanMGocan/mathrix/tree/main). This branch preserves historical source and standalone helper scripts found on the VM on 29 October 2026.

Source was checked for credentials before upload. Private environment files, databases, user uploads, dependencies, build output, logs, and browser reports are excluded. Recreate configuration from `.env.example` when setting up another machine.

Original source directory names are retained beneath `snapshots/`, individual helper files beneath `misc/`, and source recovered from runtime archives beneath `tar-snapshots/`.
